## Create a new project

```
duxt create <project-name>
```

Options:
- `--mode=static` (default) — Static site, no server needed
- `--mode=server` — Full-stack with ORM and API routes
- `--template=minimal` (default) or `--template=full`
- `--directory=<path>` — Where to create the project

---

## Start development server

```
duxt dev
duxt dev --port 9090  # Custom port
```

Starts a hot-reload dev server (default port 8080). Watches for file changes and rebuilds automatically.

### Running multiple apps simultaneously

Use different ports for each app:
```
# Terminal 1
cd app1 && duxt dev --port 8080

# Terminal 2
cd app2 && duxt dev --port 9090
```

Each app uses 5 ports starting from the base port (proxy, api, jaspr, webdev, jaspr-proxy).

---

## Generate a page

```
duxt g page <path>
```

Examples:
```
duxt g page blog/[slug]
duxt g page Admin/Posts/edit    # Namespace-aware: creates lib/admin/posts/pages/edit.dart
```

Creates a page component at the specified route path with file-based routing.
Namespace support: use `Namespace/Module/page` format (uppercase first letter = namespace).

# Duxt Server Project Structure

```
my-app/
├── pubspec.yaml              # Dart dependencies (jaspr, duxt, duxt_orm, duxt_html)
├── duxt.yaml                 # Duxt configuration (mode: server)
├── tailwind.config.js        # Tailwind CSS configuration
├── web/
│   ├── index.html            # HTML entry point
│   ├── styles.tw.css         # Tailwind input CSS
│   └── styles.css            # Compiled CSS (generated)
├── lib/
│   ├── main.dart             # App entry point — registers routes
│   ├── app.dart              # Root app component with DuxtApp
│   ├── pages/                # File-based routing (same as static)
│   │   ├── index.dart
│   │   └── blog/
│   │       ├── index.dart
│   │       └── [slug].dart
│   ├── layouts/
│   │   └── default.dart
│   ├── components/
│   │   └── header.dart
│   └── models/               # ORM models
│       └── post.dart         # Model with schema, relations
├── server/
│   ├── main.dart             # Server entry point — DuxtServer setup
│   └── api/                  # API route handlers
│       └── posts.dart        # /api/posts CRUD endpoints
├── database/
│   └── database.sqlite       # SQLite database (dev)
└── .output/                  # Build output (generated)
    ├── bundle/               # Compiled server binary
    └── public/               # Static assets
```

  void fromMap(Map<String, dynamic> map) {
    super.fromMap(map);
    token = map['token'] as String?;
    userId = map['user_id'] as int?;
    expiresAt = map['expires_at'] as String?;
  }

  @override
  Map<String, dynamic> toMap() {
    return {
      ...super.toMap(),
      'token': token,
      'user_id': userId,
      'expires_at': expiresAt,
    };
  }

  bool get isExpired {
    if (expiresAt == null) return true;
    return DateTime.parse(expiresAt!).isBefore(DateTime.now());
  }
}
```

Design decisions for sessions:
- **Database-backed sessions**: Stored in a `sessions` table rather than in-memory, so sessions survive server restarts and work across multiple server instances.
- **`expires_at` as text**: Stored as ISO 8601 string for SQLite compatibility (SQLite has no native datetime type).
- **`isExpired` helper**: Convenience getter for checking session validity in the auth middleware.
- **Session token**: Will be a UUID v4, stored both in the database and sent to the client as a cookie.

### Phase 4: Session Management

**Step 4.1: Create a session manager**

File: `/Users/flakerimi/TMP/todo/server/utils/session_manager.dart`

```dart
import 'package:duxt_orm/duxt_orm.dart';
import 'package:uuid/uuid.dart';
import '../../lib/models/session.dart';
import '../../lib/models/user.dart';

class SessionManager {
  static const _sessionDuration = Duration(hours: 24);
  static final _uuid = Uuid();

  /// Create a new session for a user. Returns the session token.
  static Future<String> createSession(int userId) async {
    final token = _uuid.v4();
    final expiresAt = DateTime.now().add(_sessionDuration).toIso8601String();

    final sessions = Model<Session>(Session());
    final session = Session()
      ..token = token
      ..userId = userId
      ..expiresAt = expiresAt;
    await sessions.create(session.toMap());

    return token;
  }

  /// Look up a session by token. Returns the User if valid, null if expired/missing.
  static Future<User?> getUserFromToken(String token) async {
    final sessions = Model<Session>(Session());
    final results = await sessions.where({'token': token}).get();
    if (results.isEmpty) return null;

    final session = results.first;
    if (session.isExpired) {
      // Clean up expired session
      await sessions.delete(session.id!);
      return null;
    }

    final users = Model<User>(User());
    final user = await users.find(session.userId!);
    return user;
  }

  /// Delete a session (logout)
  static Future<void> deleteSession(String token) async {
    final sessions = Model<Session>(Session());
    final results = await sessions.where({'token': token}).get();
    if (results.isNotEmpty) {
      await sessions.delete(results.first.id!);
    }
  }
}
```

Design decisions:
- **24-hour session duration**: Reasonable default; configurable via constant.
- **UUID v4 tokens**: Cryptographically random, effectively unguessable.
- **Lazy cleanup**: Expired sessions are deleted when encountered. A production system would add a periodic cleanup job.
- **Duxt ORM Query API**: Uses `Model<T>` with `.where()` and `.find()` following the ActiveRecord pattern from the Duxt ORM docs.

### Phase 5: Auth Middleware

**Step 5.1: Create the auth middleware**

File: `/Users/flakerimi/TMP/todo/server/middleware/auth_middleware.dart`

```dart
import 'package:duxt/duxt.dart';
import '../utils/session_manager.dart';
import '../../lib/models/user.dart';

/// Extracts the session token from the cookie header, validates it,
/// and attaches the authenticated User to the request context.
/// Returns a 401 Response if no valid session is found.
Future<dynamic> authMiddleware(Request req) async {
  final cookieHeader = req.headers['cookie'] ?? '';
  final token = _extractSessionToken(cookieHeader);

  if (token == null) {
    return Response.json(
      {'error': 'Authentication required'},
      status: 401,
    );
  }

  final user = await SessionManager.getUserFromToken(token);
  if (user == null) {
    return Response.json(
      {'error': 'Invalid or expired session'},
      status: 401,
    );
  }

  // Attach user to request context for downstream handlers
  req.context['user'] = user;
  return null; // null means "continue to the route handler"
}

/// Parse the Cookie header to extract the session_token value.
String? _extractSessionToken(String cookieHeader) {
  if (cookieHeader.isEmpty) return null;
  final cookies = cookieHeader.split(';').map((c) => c.trim());
  for (final cookie in cookies) {
    if (cookie.startsWith('session_token=')) {
      return cookie.substring('session_token='.length);
    }
  }
  return null;
}
```

Middleware design:
- **Return null to continue**: Following the Duxt middleware pattern, returning `null` lets the request pass through to the route handler. Returning a `Response` short-circuits and sends that response immediately.
- **`req.context['user']`**: Attaches the authenticated `User` object so route handlers can access it without re-querying the database.
- **Cookie parsing**: Manual extraction from the `Cookie` header since Duxt works with raw headers. The cookie name is `session_token`.

### Phase 6: Auth API Routes

**Step 6.1: Create auth API routes**

File: `/Users/flakerimi/TMP/todo/server/api/auth.dart`

```dart
import 'package:duxt/duxt.dart';
import 'package:duxt_orm/duxt_orm.dart';
import '../../lib/models/user.dart';
import '../utils/password.dart';
import '../utils/session_manager.dart';
import '../middleware/auth_middleware.dart';

void registerAuthApi(DuxtServer server) {

  // POST /api/auth/register
  server.post('/api/auth/register', (req) async {
    final body = await req.body();

    final email = body['email'] as String?;
    final password = body['password'] as String?;
    final name = body['name'] as String?;

    // Validation
    if (email == null || email.isEmpty ||
        password == null || password.isEmpty ||
        name == null || name.isEmpty) {
      return Response.json(
        {'error': 'Email, password, and name are required'},
        status: 400,
      );
    }

    if (password.length < 8) {
      return Response.json(
        {'error': 'Password must be at least 8 characters'},
        status: 400,
      );
    }

    // Check for existing user
    final users = Model<User>(User());
    final existing = await users.where({'email': email}).get();
    if (existing.isNotEmpty) {
      return Response.json(
        {'error': 'Email already registered'},
        status: 409,
      );
    }

    // Create user with hashed password
    final hashedPassword = PasswordHelper.hash(password);
    final userData = {
      'email': email,
      'password': hashedPassword,
      'name': name,
    };
    final user = await users.create(userData);

    // Create session
    final token = await SessionManager.createSession(user.id!);

    return Response.json(
      {'message': 'Registration successful', 'user': user.toSafeMap()},
      status: 201,
      headers: {
        'Set-Cookie': 'session_token=$token; HttpOnly; Path=/; '
            'SameSite=Strict; Max-Age=86400',
      },
    );
  });

  // POST /api/auth/login
  server.post('/api/auth/login', (req) async {
    final body = await req.body();

    final email = body['email'] as String?;
    final password = body['password'] as String?;

    if (email == null || password == null) {
      return Response.json(
        {'error': 'Email and password are required'},
        status: 400,
      );
    }

    // Find user by email
    final users = Model<User>(User());
    final results = await users.where({'email': email}).get();
    if (results.isEmpty) {
      return Response.json(
        {'error': 'Invalid email or password'},
        status: 401,
      );
    }

    final user = results.first;

    // Verify password
    if (!PasswordHelper.verify(password, user.password!)) {
      return Response.json(
        {'error': 'Invalid email or password'},
        status: 401,
      );
    }

    // Create session
    final token = await SessionManager.createSession(user.id!);

    return Response.json(
      {'message': 'Login successful', 'user': user.toSafeMap()},
      headers: {
        'Set-Cookie': 'session_token=$token; HttpOnly; Path=/; '
            'SameSite=Strict; Max-Age=86400',
      },
    );
  });

  // POST /api/auth/logout
  server.post('/api/auth/logout', (req) async {
    final cookieHeader = req.headers['cookie'] ?? '';
    final token = _extractToken(cookieHeader);

    if (token != null) {
      await SessionManager.deleteSession(token);
    }

    return Response.json(
      {'message': 'Logged out successfully'},
      headers: {
        'Set-Cookie': 'session_token=; HttpOnly; Path=/; '
            'SameSite=Strict; Max-Age=0',
      },
    );
  });

  // GET /api/auth/me (protected)
  server.get('/api/auth/me', (req) async {
    final result = await authMiddleware(req);
    if (result != null) return result; // 401 response

    final user = req.context['user'] as User;
    return Response.json({'user': user.toSafeMap()});
  });
}

String? _extractToken(String cookieHeader) {
  if (cookieHeader.isEmpty) return null;
  final cookies = cookieHeader.split(';').map((c) => c.trim());
  for (final cookie in cookies) {
    if (cookie.startsWith('session_token=')) {
      return cookie.substring('session_token='.length);
    }
  }
  return null;
}
```

Design decisions for auth endpoints:
- **Registration**: Validates input, checks for duplicate email (409 Conflict), hashes password with bcrypt, creates user, auto-creates session and sets cookie so the user is logged in immediately after registration.
- **Login**: Finds user by email, verifies password hash, creates new session. Generic error message "Invalid email or password" to prevent email enumeration.
- **Logout**: Deletes the server-side session record and expires the cookie (`Max-Age=0`).
- **GET /me**: Uses the auth middleware inline. This is for the single protected auth endpoint; the todo routes use middleware more systematically.
- **Cookie security flags**: `HttpOnly` (no JS access), `SameSite=Strict` (CSRF protection), `Path=/` (sent for all routes), `Max-Age=86400` (24 hours).

```dart
import 'package:duxt/duxt.dart';
import 'package:duxt_orm/duxt_orm.dart';
import '../../lib/models/todo.dart';
import '../../lib/models/user.dart';
import '../middleware/auth_middleware.dart';

void registerTodoApi(DuxtServer server) {
  // Helper: apply auth middleware and return the user, or null if unauthorized
  Future<User?> authenticate(Request req) async {
    final result = await authMiddleware(req);
    if (result != null) return null;
    return req.context['user'] as User;
  }

  // GET /api/todos - List all todos for the authenticated user
  server.get('/api/todos', (req) async {
    final authResult = await authMiddleware(req);
    if (authResult != null) return authResult;

    final user = req.context['user'] as User;
    final todos = Model<Todo>(Todo());
    final userTodos = await todos.where({'user_id': user.id}).get();

    return Response.json({
      'todos': userTodos.map((t) => t.toMap()).toList(),
    });
  });

  // POST /api/todos - Create a new todo
  server.post('/api/todos', (req) async {
    final authResult = await authMiddleware(req);
    if (authResult != null) return authResult;

    final user = req.context['user'] as User;
    final body = await req.body();

    final title = body['title'] as String?;
    if (title == null || title.isEmpty) {
      return Response.json(
        {'error': 'Title is required'},
        status: 400,
      );
    }

    final todos = Model<Todo>(Todo());
    final todo = await todos.create({
      'title': title,
      'completed': false,
      'user_id': user.id,
    });

    return Response.json(
      {'message': 'Todo created', 'todo': todo.toMap()},
      status: 201,
    );
  });

  // GET /api/todos/:id - Get a specific todo
  server.get('/api/todos/:id', (req) async {
    final authResult = await authMiddleware(req);
    if (authResult != null) return authResult;

    final user = req.context['user'] as User;
    final id = int.tryParse(req.params['id'] ?? '');

    if (id == null) {
      return Response.json({'error': 'Invalid todo ID'}, status: 400);
    }

    final todos = Model<Todo>(Todo());
    final todo = await todos.find(id);

    if (todo == null) {
      return Response.json({'error': 'Todo not found'}, status: 404);
    }

    // Ownership check
    if (todo.userId != user.id) {
      return Response.json({'error': 'Todo not found'}, status: 404);
    }

    return Response.json({'todo': todo.toMap()});
  });

  // PUT /api/todos/:id - Update a todo
  server.put('/api/todos/:id', (req) async {
    final authResult = await authMiddleware(req);
    if (authResult != null) return authResult;

    final user = req.context['user'] as User;
    final id = int.tryParse(req.params['id'] ?? '');

    if (id == null) {
      return Response.json({'error': 'Invalid todo ID'}, status: 400);
    }

    final todos = Model<Todo>(Todo());
    final todo = await todos.find(id);

    if (todo == null || todo.userId != user.id) {
      return Response.json({'error': 'Todo not found'}, status: 404);
    }

    final body = await req.body();
    final updateData = <String, dynamic>{};

    if (body.containsKey('title')) {
      updateData['title'] = body['title'];
    }
    if (body.containsKey('completed')) {
      updateData['completed'] = body['completed'];
    }

    final updated = await todos.update(id, updateData);

    return Response.json({
      'message': 'Todo updated',
      'todo': updated.toMap(),
    });
  });

  // DELETE /api/todos/:id - Delete a todo
  server.delete('/api/todos/:id', (req) async {
    final authResult = await authMiddleware(req);
    if (authResult != null) return authResult;

    final user = req.context['user'] as User;
    final id = int.tryParse(req.params['id'] ?? '');

    if (id == null) {
      return Response.json({'error': 'Invalid todo ID'}, status: 400);
    }

    final todos = Model<Todo>(Todo());
    final todo = await todos.find(id);

    if (todo == null || todo.userId != user.id) {
      return Response.json({'error': 'Todo not found'}, status: 404);
    }

    await todos.delete(id);

    return Response.json({'message': 'Todo deleted'});
  });
}
```

Key design decisions for Todo routes:
- **Per-user isolation**: Every query filters by `user_id`. When a user tries to access another user's todo, the response is 404 (not 403) to avoid leaking information about the existence of resources.
- **Auth middleware applied to every route**: Each handler calls `authMiddleware(req)` first. If it returns a non-null value (a 401 Response), the handler returns that immediately.
- **Partial updates**: The PUT handler only updates fields that are present in the request body, allowing partial updates.
- **Input validation**: Title is required for creation; ID is validated as a parseable integer.

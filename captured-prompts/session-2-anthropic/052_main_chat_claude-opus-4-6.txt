### Step 3: Create utilities in `server/utils/`

- **`session_manager.dart`** — `createSession(userId)` returns token, `getUserFromToken(token)` returns User or null, `deleteSession(token)` for logout. Sessions are stored in DB, expire after 24h.

### Step 4: Create auth middleware in `server/middleware/`

- **`auth_middleware.dart`** — Extracts `session_token` cookie, validates via `SessionManager`, attaches `User` to `req.context['user']`. Returns 401 if invalid.

### Step 5: Create API routes in `server/api/`

- **`auth.dart`** — Register (validate input, check duplicate email, hash password, create user + session, set cookie), Login (verify password, create session), Logout (delete session, expire cookie), Me (return current user)
- **`todos.dart`** — Full CRUD, every handler calls `authMiddleware` first, all queries scoped to `user_id`. Ownership check returns 404 (not 403) to avoid leaking info.

Cookie flags: `HttpOnly; SameSite=Strict; Path=/; Max-Age=86400`

### Step 6: Wire up in `server/main.dart`

Register both `registerAuthApi(server)` and `registerTodoApi(server)`, then `server.start()`.

  String? email;
  String? name;

  User({int? id, this.email, this.name}) : _id = id;

  @override
  dynamic get id => _id;
  @override
  set id(dynamic value) => _id = value as int?;

  @override
  Map<String, dynamic> toMap() => {'email': email, 'name': name};

  factory User.fromRow(Map<String, dynamic> row) => User(
    id: row['id'] as int?,
    email: row['email'] as String?,
    name: row['name'] as String?,
  );

  // Relations (access loaded data)
  List<Post> get posts => getRelation<List<Post>>('posts') ?? [];

  static void register() {
    Entity.registerModel<User>(User.fromRow, schema: {
      'id': Column.integer().primaryKey().autoIncrement(),
      'email': Column.string().notNull().unique(),
      'name': Column.string(100).nullable(),
    });
    Entity.registerRelation<User>('posts', HasMany<Post>(foreignKey: 'user_id'));
  }
}

| `<object>` | `ObjectEmbed` | Conflicts with Dart Object |
| `<map>` | `ImageMap` | Conflicts with Dart Map |
| `<var>` | `HtmlVar` | Conflicts with Dart var |
| `<style>` | `StyleElement` | Conflicts with Styles type |
| `<template>` | `HtmlTemplate` | Conflicts with Dart Template |
| `<data>` | `HtmlData` | Conflicts with common variable names |

### Important Notes

- `RawText` must be imported separately: `import 'package:jaspr/dom.dart' show RawText;`
- When using with `jaspr/jaspr.dart`, add `hide Text` to avoid ambiguous import: `import 'package:jaspr/jaspr.dart' hide Text;`
- Input/Button types are strings: `Input(type: 'text')`, `Button(type: 'button')`
- Form has no `onSubmit` - use `events: {'submit': handler}`

## duxt_signals (v0.1.2) - Reactive State

### Import

```dart
import 'package:duxt_signals/duxt_signals.dart';
```

### Signal (Mutable Reactive Value)

```dart
final count = signal(0);

count()              // Read value (call syntax)
count.value          // Read value (property)
count.set(5)         // Set value
count.update((v) => v + 1)  // Update with function
count.listen((v) { })       // Subscribe to changes
```

### Computed (Derived Reactive Value)

```dart
final firstName = signal('John');
final lastName = signal('Doe');
final fullName = computed(() => '${firstName()} ${lastName()}');
// Auto-tracks dependencies, recomputes when they change
```

### Effect (Side Effects)

```dart
final dispose = effect(() {
  print('Count changed: ${count()}');  // Runs when count changes
});
dispose();  // Stop effect
```

### Batch Updates

```dart
batch(() {
  signal1.set(value1);
  signal2.set(value2);
});  // Notifications deferred until batch completes
```

### SignalState (Auto-Tracking Component)

```dart
class MyComponent extends SignalState<MyComponent> {
  final count = signal(0);

  @override
  Component buildComponent() {
    // Signals read here are auto-tracked
    return Div(children: [Text('Count: ${count()}')]);
  }
}
```

### FormField (Signal + Validation)

```dart
final email = formField('', validators: [
  required('Email is required'),
  email('Invalid email format'),
]);

email()            // Current value
email.touched      // Has been focused/blurred
email.dirty        // Changed from initial
email.error        // Validation error message (String?)
email.isValid      // No errors
email.hasError     // Has errors

email.set('new@email.com')  // Set and validate
email.touch()               // Mark as touched
email.reset()               // Reset to initial
email.validate()            // Manual validation
```

### Built-in Validators

```dart
required('Required')              // String not empty
requiredValue<T>('Required')      // Value not null
minLength(3, 'Too short')         // Min string length
maxLength(100, 'Too long')        // Max string length
email('Invalid email')            // Email format
pattern(RegExp(r'...'), 'Invalid') // Regex match
min(0, 'Must be >= 0')            // Number minimum
max(100, 'Must be <= 100')        // Number maximum
notEmpty<T>('List empty')         // List not empty
```

### Important Notes

- Avoid naming variables `email` or `form` - they shadow the `email()` validator and jaspr's `form()` function.
- Input blur events: use `events: {'blur': (_) => field.touch()}` not `onBlur`.

### Typical Server Setup

```dart
import 'package:duxt/server.dart';
import 'package:duxt_orm/duxt_orm.dart';

void main() async {
  await DuxtOrm.init(dbConfig);
  User.register();
  Post.register();
  await DuxtOrm.migrate();

  final server = DuxtServer(
    port: int.parse(Platform.environment['PORT'] ?? '3001'),
    apiDir: 'server/api',
    staticDir: '.output/public',
    middleware: [
      securityHeaders(),
      bodyLimit(),
      cors(origins: ['http://localhost:4000']),
      jsonBody(),
      logger(),
    ],
  );

  server.get('/api/posts', (req) async {
    final posts = await Model<Post>().include(['author']).all();
    return json(posts.map((p) => p.toMap()).toList());
  });

  await server.start();
}
```

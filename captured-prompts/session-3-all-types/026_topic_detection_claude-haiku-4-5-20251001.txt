## Implementation Steps

### Step 1: Scaffold the project
```bash
cd /Users/flakerimi/TMP
duxt create todo --mode=server
```
Then add `dbcrypt` (bcrypt hashing) and `uuid` (session tokens) to `pubspec.yaml` and run `dart pub get`.

### Step 2: Create 3 models in `lib/models/`

- **User** (`user.dart`) — `email`, `password` (hashed), `name` + a `toSafeMap()` that excludes password
- **Todo** (`todo.dart`) — `title`, `completed` (bool), `user_id` (int)
- **Session** (`session.dart`) — `token`, `user_id`, `expires_at` + an `isExpired` getter

All use Duxt ORM's `Model` base class with `tableName`, `schema`, `fromMap`, `toMap`. Tables are auto-migrated on server start.

### Step 3: Create utilities in `server/utils/`

- **`password.dart`** — `PasswordHelper.hash(password)` / `PasswordHelper.verify(password, hash)` using bcrypt (12 rounds)
- **`session_manager.dart`** — `createSession(userId)` returns token, `getUserFromToken(token)` returns User or null, `deleteSession(token)` for logout. Sessions are stored in DB, expire after 24h.

### Step 4: Create auth middleware in `server/middleware/`

- **`auth_middleware.dart`** — Extracts `session_token` cookie, validates via `SessionManager`, attaches `User` to `req.context['user']`. Returns 401 if invalid.

### Step 5: Create API routes in `server/api/`

- **`auth.dart`** — Register (validate input, check duplicate email, hash password, create user + session, set cookie), Login (verify password, create session), Logout (delete session, expire cookie), Me (return current user)
- **`todos.dart`** — Full CRUD, every handler calls `authMiddleware` first, all queries scoped to `user_id`. Ownership check returns 404 (not 403) to avoid leaking info.

Cookie flags: `HttpOnly; SameSite=Strict; Path=/; Max-Age=86400`

### Step 6: Wire up in `server/main.dart`

Register both `registerAuthApi(server)` and `registerTodoApi(server)`, then `server.start()`.

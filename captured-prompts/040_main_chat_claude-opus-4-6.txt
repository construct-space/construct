### Step 4: Create auth middleware in `server/middleware/`

### Step 5: Create API routes in `server/api/`

- **`auth.dart`** — Register (validate input, check duplicate email, hash password, create user + session, set cookie), Login (verify password, create session), Logout (delete session, expire cookie), Me (return current user)
- **`todos.dart`** — Full CRUD, every handler calls `authMiddleware` first, all queries scoped to `user_id`. Ownership check returns 404 (not 403) to avoid leaking info.

Cookie flags: `HttpOnly; SameSite=Strict; Path=/; Max-Age=86400`

### Step 6: Wire up in `server/main.dart`

Register both `registerAuthApi(server)` and `registerTodoApi(server)`, then `server.start()`.
